# Итоговый отчёт: ML-прогноз свойств шинных резиновых смесей и обратный дизайн рецептур

## Цель

Исследовательский вопрос (Q1): могут ли опубликованные ML-методы для полимеров и резины в сочетании с открытыми данными достаточно точно предсказывать свойства шинной резиновой смеси по её рецептуре, чтобы предлагать новые рецептуры с целевыми свойствами? Задача-ориентир — рецептура протектора легкового шинного протектора с вязкостью по Муни (Mooney viscosity) 55–65 и M300 ≥ 10 МПа. Работа — чисто вычислительная (in-silico): без лабораторных экспериментов, на открытых патентных данных (tires_2.csv: 3774 смесей из 337 патентов, ограничение C1/C4).

## Подход

Исследование декомпозировано на пять гипотез, каждая с методами проверки (VerificationMethod), критериями подтверждения (CC1–CC5) и единицами свидетельств (Evidence, E1–E9):

- **H1** — применимость опубликованных методов: polyBERT (https://huggingface.co/xushijie/polyBERT), PolymerGNN (https://github.com/owencqueen/PolymerGNN), TransPolymer (https://github.com/ChangwenXu98/TransPolymer). Метод проверки VM1: клонирование/запуск репозиториев, проверка весов, лицензий и прогонки (свидетельства E2–E4, CoderAgent).
- **H2** — прямые модели «рецептура (phr) → свойства» со стандартными регрессорами; метод VM2 (завершён): очистка данных, обработка пропусков, признаки plain-phr против polyBERT-эмбеддингов (5×600 blend-векторов через embed_blend, GD2/GD3), Ridge в замкнутой форме (ансамбли деревьев заблокированы политикой песочницы — задокументированное ограничение среды).
- **H3** — утечка данных: из-за почти дублирующихся строк внутри одного патента случайные разбиения завышают метрики; метод VM3 — сравнение 5-fold random CV против GroupKFold по патентам (свидетельство E7, подтверждено заключением CL3).
- **H4** — ограниченный обратный дизайн: поиск по phr-пространству в реалистичных границах (эластомерная смесь из {NR, SBR, BR, IIR, EPDM} в сумме 100 phr, наполнитель 40–100 phr, масло 0–40, стандартный пакет вулканизации) для 5 кандидатных рецептур с интервальными оценками (свидетельство E9, заключение CL4; все сиды = 42).
- **H5** — добавляют ли параметры процесса и марки ингредиентов ≥0.03 R² — **отложена** (postponed) в бэклог.

Роли распределены по ограничению C6 (вычислительный материаловед-аналитик, кодер, валидатор и т.д.); стоимость — только вычислительная (CM1, R1: бюджет 0).

## Результаты

### 1. Обзор опубликованных методов (H1 — подтверждена содержательно)

Ни один из трёх методов не принимает phr-рецептуру напрямую; работоспособный путь — пер-эластомерные эмбеддинги, взвешенные по phr-долям:

| Метод | Вердикт | Детали (свидетельства) |
|---|---|---|
| polyBERT | usable-as-featurizer | готовый инструмент embed_blend; 3677/3774 строк датасета встроено; лицензия не указана (E2) |
| PolymerGNN | adaptable | работает только на PyG 2.3.1; вход — .xyz-графы мономеров + mol%, не phr; лицензии в репозитории нет (E3) |
| TransPolymer | usable-as-featurizer | MIT-лицензия, pretrained-веса в комплекте (314 МБ), 768-dim CLS-эмбеддинги (E4) |

### 2. Прямые модели (H2 — негативный результат по CC3; H3 — подтверждена)

Лучший вариант — plain-phr признаки; polyBERT-представления хуже на всех разбиениях (свидетельство E8: M300 R² 0.161 vs 0.434 на 5-fold random; Mooney 0.030 vs 0.218). Протоколы: одиночное 80/20 | 5-fold random CV | 5-fold GroupKFold по патентам; Ridge alpha=1, seed 42:

| Свойство | R² (80/20 / random CV / group) | MAE (групповое) |
|---|---|---|
| Mooney | 0.206 / 0.218 / **−0.025** | 18.5 |
| M300 | 0.444 / 0.434 / **0.265** | 3.17 |
| Прочность | 0.232 / 0.219 / −0.436 | 8.5 |
| Твёрдость | 0.507 / 0.498 / −0.681 | 9.2 |

Критерий CC3 (MAE ≤3 для Mooney, ≤1.5 МПа для M300) **не выполнен** (получено ~15.5 и ~2.77) — задокументированный валидный негативный результат.

**Утечка подтверждена (H3, CC4):** деградация random → held-out-patent по ΔR² от −0.169 (M300) до −1.18 (твёрдость); MAE растёт на 14–59%. Причина — кластеризация «рецептура → свойство» на уровне патентов, включая 457 групп точных дубликатов внутри патентов. Следствие: групповое разбиение по патентам — обязательное для любых заявлений о доверии (заключение CL3).

### 3. Обратный дизайн (H4): 5 кандидатных рецептур

Целевое окно (Mooney 55–65, M300 ≥ 10 МПа) достигнуто моделью для всех 5 кандидатов (свидетельство E9: предсказанный Mooney 57.3–64.1, M300 10.0–14.8 МПа), например:

- **A:** SBR 70/BR 30, техуглерод 33 + кремнезём 63, силан 5.1, масло 22 → Mooney 62.1, M300 10.04 МПа (kNN-дистанция 2.40, экстраполяция);
- **B:** NR 40/SBR 40/BR 20, техуглерод 72 → Mooney 57.3, M300 13.0 МПа;
- **D:** NR 60/SBR 40, техуглерод 49 → Mooney 64.1, M300 14.8 МПа.

**Честные ограничения (по C4/CC5):** все предсказания — вычислительные гипотезы; Mooney-прогнозы имеют низкую достоверность (групповой R² отрицателен; интервал ±15 ед. покрывает почти всё окно); все 5 кандидатов помечены как экстраполятивные (5-NN дистанции 2.06–2.65 при p95 обучения 2.03). Полные рецептуры с бутстреп-интервалами: `~/h4_verification/results/candidates.json/.md`.

## Обсуждение

Ответ на Q1 — **частично да, с серьёзными оговорками**. Открытые патентные данные и опубликованные методы дают воспроизводимый конвейер «рецептура → свойства → кандидатные рецептуры» (заключения CL1–CL4), но точность скромная. Случайные разбиения дают умеренный R², а честное разбиение по патентам — реальный сценарий «новая рецептура» — обрушивает качество: для Mooney групповой R² = −0.025 (хуже среднего по обучению). Предложенные рецептуры — экстраполятивные вычислительные гипотезы, а не готовые к производству решения.

Ключевые несоответствия и разочарования, зафиксированные честно:
- polyBERT-эмбеддинги не улучшают plain-phr признаки ни на одном разбиении — молекулярное представление само по себе не компенсирует нехватку данных о наполнителях и процессе;
- ансамбли деревьев оказались недоступны (блокировка политикой песочницы), поэтому сравнение ограничено Ridge в замкнутой форме (E7);
- H4 процедурно выполнена (5 рецептур, окно достигнуто, неопределённости приведены), но статус остаётся inconclusive именно из-за слабости Mooney-модели на групповом разбиении — предсказания Mooney для кандидатов нельзя считать надёжными.

## Ограничения и дальнейшие шаги

Ограничения:
1. Только вычислительное исследование — ни одна рецептура не проверена в лаборатории (C1/C4).
2. Датасет патентный: однообразие рецептур и дубликаты внутри патентов (C5) ограничивают обобщение; 457 групп дубликатов завышают random-метрики.
3. Доступен только Ridge (линейная модель); нелинейные ансамбли заблокированы средой.
4. Все 5 кандидатных рецептур экстраполятивны (5-NN дистанция > p95 обучения).

Дальнейшие шаги:
1. **H5 (отложена):** проверить, добавляют ли параметры процесса и марки/типы ингредиентов ≥0.03 R² поверх plain-phr — логичное продолжение, напрямую нацеленное на слабость групповых метрик.
2. Расширить датасет за пределы патентов (лабораторные наборы) и/или провести дедупликацию по рецептурам.
3. Повторить бенчмарк с нелинейными моделями в среде без блокировок.
4. Лабораторная валидация хотя бы одной кандидатной рецептуры (например, B или D — ближе к домену обучения) с целевым окном Mooney 55–65, M300 ≥ 10 МПа.

Все скрипты, логи и данные сохранены для повторного использования: `~/h1_verification/`, `~/h2_verification/`, `~/h4_verification/` (все сиды зафиксированы = 42). Главный итог — не «готовые рецептуры», а честно измеренные пределы применимости метода (слабость на новых патентах) и сохранённая инфраструктура для продолжения работы.
