# Кейс с резиной: постановка и метрика (B1)

## Данные
`tires_2.csv`: 3774 смеси из 337 патентов, 78 колонок. Состав в phr, марки и типы компонентов, параметры процесса, 12 целевых свойств с пропусками.

## Задача
1. **Прямая:** по рецептуре и процессу предсказать свойство смеси. Основные цели: вязкость по Муни (1282 строки, 120 патентов) и M300 (1517 строк, 177 патентов). Дополнительные: прочность, удлинение, твёрдость, tan δ при 60 °C.
2. **Обратная:** поверх прямой модели найти рецептуры под заданные значения свойств и показать кандидатов с оценкой неопределённости.

## Метрика
R² и MAE при 5-кратной проверке с разбиением **по `patent_id`** (GroupKFold). Случайное разбиение приводится рядом для сравнения с результатом Наргизы.

Строки одного патента отличаются одним-двумя компонентами. При случайном разбиении почти одинаковые смеси попадают и в обучение, и в тест.

## Опорная модель
`baseline/phr_baseline.py`, HistGradientBoosting, 17 сентября 2026. Результаты в `baseline/phr_baseline.json`.

| Свойство | Строк | Патентов | R² phr, случайное | R² phr, по патентам | R² все числовые, случайное | R² все числовые, по патентам |
|---|---|---|---|---|---|---|
| mooney_viscosity | 1282 | 120 | 0.58 | −0.06 | 0.76 | −0.20 |
| tensile_strength_MPa | 1757 | 189 | 0.30 | −0.52 | 0.79 | −0.06 |
| elongation_at_break_percent | 1580 | 188 | 0.59 | −0.26 | 0.72 | −0.07 |
| M300_MPa | 1517 | 177 | 0.84 | 0.31 | 0.86 | 0.22 |
| hardness_shore_A | 1070 | 127 | 0.80 | −0.10 | 0.81 | −0.05 |
| tan_delta_60C | 710 | 89 | 0.94 | −0.27 | 0.91 | −0.48 |

Это воспроизводит наблюдение Наргизы: около 0.7 внутри домена и ниже нуля на незнакомом. Перенос на новый патент сейчас работает только для M300.

## Что считается успехом кейса
- Система сама приходит к разбиению по патентам или явно обсуждает утечку.
- Признаки из серверов Alembic (эмбеддинги polyBERT для каучуков, при возможности PolymerGNN) сравниваются с phr на одном и том же разбиении.
- Прирост R² по патентам хотя бы на одном свойстве считается положительным результатом. Отсутствие прироста считается отрицательным результатом с сохранёнными инструментами, сессией и графом.
- Обратная задача выдаёт список рецептур-кандидатов для заданных Муни и M300.

## Эталоны для сравнения
- Ручной результат Наргизы (см. README, раздел 6).
- Эта опорная модель.
- Claude Code или opencode на той же модели с тем же промптом (E1).

## Пробное решение с polyBERT (B2, 17 сентября 2026)
`baseline/polybert_features.py`. Эмбеддинги девяти каучуков получены вызовами `embed_psmiles` сервера `polyBERT-fac250`. Вектор смеси равен среднему по долям каучуков в phr, затем PCA до 8 компонент. Модель и разбиение по патентам те же.

| Свойство | phr | phr + polyBERT | только polyBERT |
|---|---|---|---|
| mooney_viscosity | −0.06 | −0.07 | −0.01 |
| tensile_strength_MPa | −0.52 | −0.52 | −0.12 |
| elongation_at_break_percent | −0.26 | 0.10 | 0.05 |
| M300_MPa | 0.31 | 0.25 | 0.16 |
| hardness_shore_A | −0.10 | −0.08 | −0.11 |
| tan_delta_60C | −0.27 | −0.28 | −0.04 |

Эмбеддинги каучуков переноса между патентами не дают. Заметный сдвиг есть только у удлинения (с −0.26 до 0.10). Это совпадает с выводом Наргизы: polyBERT обучен на полимерах вообще, а разброс свойств в патентах задают наполнитель, вулканизующая система и процесс. Ожидаемый итог кейса отрицательный по качеству прогноза и положительный по артефактам.

Замечания по пути для агента:
- Длинный результат инструмента обрезается до 20 чисел. Полный вектор лежит в `result_s3` (bucket и `s3_key`). Агент должен это прочитать и скачать файл, иначе получит 20 чисел вместо 600.
- `presigned_url` подписан для хоста `0.0.0.0:19000`. С машины, где идёт прогон, он открывается.
- Каждый вызов `embed_psmiles` занимает 15–20 секунд: модель загружается заново на CPU. Для таблиц нужен `embed_table`.

## Пробное решение с mordred (C7, 18 сентября 2026)
`baseline/mordred_fetch.py` и `baseline/mordred_features.py`. Дескрипторы 14 ингредиентов (ускорители, антиоксиданты, силаны) получены вызовом `descriptors_from_smiles` сервера `mordred-community-10e89b`: 815 пригодных дескрипторов, PCA до 6 компонент, вес по phr ингредиента. R² при разбиении по патентам:

| Свойство | phr | phr + тип ингредиента | phr + mordred |
|---|---|---|---|
| mooney_viscosity | −0.06 | −0.09 | −0.01 |
| tensile_strength_MPa | −0.52 | −1.02 | −1.05 |
| elongation_at_break_percent | −0.26 | −0.30 | −0.46 |
| M300_MPa | 0.31 | 0.29 | 0.33 |
| hardness_shore_A | −0.10 | 0.01 | −0.20 |
| tan_delta_60C | −0.27 | −0.14 | −0.13 |
| t90_min | −0.33 | −0.22 | −0.15 |

Систематического прироста нет: сдвиги в пределах разброса между признаковыми наборами, знак меняется от свойства к свойству. Химия малых молекул переноса между патентами тоже не даёт. Гипотеза из `research/extra_tools.md` не подтвердилась. Сервер mordred остаётся полезным артефактом каталога, в статье его вклад в качество прогноза не заявляем.
