\section*{Ethics Statement}
Alembic executes LLM-generated shell commands and arbitrary repository code; all pipeline stages run inside an ephemeral, isolated Docker container that is the intended security boundary, and generated servers are validated before being exposed. We only process publicly available GitHub repositories and do not download or redistribute any dataset beyond what a repository's own installation already fetches. As with any system that runs LLM-generated code, users deploying generated MCP servers outside the sandboxed pipeline should apply their own standard container-isolation practices.
